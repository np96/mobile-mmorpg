generation call per distinct ability. No external reference images were used.

Every accepted prompt used this common direction:

> Use case: stylized-concept. Asset type: one square game UI ability icon for the
> named Rogue ability. Premium serious dark-fantasy hand-painted realism suitable
> for a Diablo-like action RPG, with crisp readable silhouette at mobile HUD size.
> Palette centered on blackened steel and worn black leather, with only restrained
> ability-colored energy. Dramatic upper-left rim light, deep shadows, tactile metal
> and leather brushwork. Center one compact motif occupying about 72-74% of the
> canvas with at least 10% clean padding on all sides. Square 1:1 composition.
> Background must be fully opaque, perfectly uniform near-black #080A0D matte,
> edge to edge: no transparency, no checkerboard, no gradient, no vignette, and no
> background texture. No frame, circle, button bezel, text, letters, runes, logo,
> watermark, character portrait, cartoon or flat-vector style, or excessive bloom.
